# 📊 Executive Dashboard & Business Analytics Engine

Standalone, visual analytics dashboard component featuring real-time revenue KPIs, category sales breakdowns, profit margin trends, and sales velocity metrics.

## 📦 Features
- **Real-Time KPIs**: Total Revenue, Average Order Value, Net Profit, and Growth Trends.
- **Category Sales Breakdown**: Percentage share calculations across Groceries, Dairy, and FMCG.
- **Monthly Revenue Projections**: Net profit vs expense visualizations.

## 🚀 Quick Integration

```typescript
import { calculateExecutiveDashboardMetrics } from './modules/dashboard-analytics';

const metrics = calculateExecutiveDashboardMetrics(salesBillArray);
```
